## 自动化范围

`npm test`：15 项，源文件 `tests/core.test.ts`。

`npm run test:e2e`：6 项，源文件 `e2e/app.spec.ts`、`e2e/cold-start.spec.ts`。

完整浏览器冷启动测试用单独的持久用户目录：联网录入装备和照片，缓存完成后关闭浏览器进程，再以 offline 模式重新启动进程，导航站点、确认照片、修改重量并刷新读取。其他离线场景包含装备、临时打包物品、食物、餐食、实际费用和待购新增，以及装备修改删除。

这证明本次桌面 Chrome 环境下的离线冷启动路径可用，不代表所有移动系统环境均已验收。自动化未穷举每种浏览器与每个字段组合。
